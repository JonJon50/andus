# AndUs

AndUs is a Laravel-based business website for showcasing web development, AI automation, database systems, and digital services.

## Tech Stack

- Laravel
- Blade
- Tailwind CSS
- Livewire
- Vite
- MySQL / MariaDB

## Pages

- Home
- About
- Services
- Events
- Contact

## Local Setup

composer install
npm install
cp .env.example .env
php artisan key:generate
php artisan serve
npm run dev
